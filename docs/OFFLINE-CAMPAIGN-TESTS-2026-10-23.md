# Offline Campaign and checkpoint tests – v0.5.1
Date: 2026-10-23

## Functional contract
- All numbers are generated by deterministic fixtures, not live OSRS data.
- One synthetic activity is selected by `GoalPlanner.Rank` per simulated step.
- Skill +1 (capped at 99) and fictional +100 GP per step, always respecting the reserve.
- The campaign can be paused and resumed with a JSON checkpoint under the user's
  local profile. The file contains *no account identity, tokens, passwords or official
  game state*.
- Checkpoint includes source marker `SYNTHETIC_FIXTURE`. Unsupported/corrupt,
  incomplete or non-synthetic inputs are rejected without overwriting the original.
- Atomic file replacement on the same volume uses a temporary file.
- A checked Save/Resume test compares 120 uninterrupted steps with 60+60 steps.
- WinForms runs the fixture batch off the UI thread and surfaces the result in logs.

## Test matrix
| Test | Assertion |
|---|---|
| Progress | 120 actions, 120 levels gained in synthetic account |
| Fictitious cashflow | 120 steps yield exactly 12,000 synthetic coins |
| Recovery | 60 steps saved + 60 resumed equals 120 uninterrupted |
| Corruption | malformed JSON is rejected, original left untouched |
| Data provenance | live-labelled checkpoint is rejected |
| Post-max behavior | no levels exceed 99 and profit mode continues |

## Missing before real automation
Legitimate and explicitly authorized game state, real XP and requirements data,
quest-/bank-/inventory snapshots, live price quotes, action execution and
confirmation are **not** implemented in the campaign.
The fixture is designed to evaluate the *planner*, not claim progression on
Jagex servers. For any sanctioned live experiment, use the operator and
account controls documented separately; no technical ban immunity can be
guaranteed.
